Git

  • git clone - клонирование удаленного репозитория.
  • git status - отображение внесенных изменений в файл.
  • git add - добавление файла в отслеживаемый.
  • git push - внесение изменений в удаленный репозиторий.
  • git log - выводит список всех коммитов.
  • git pull - подтягивает изменения из удаленного локального репозитория.
  • git commit -m "first commit" - делается коммит.
